# 프로젝트 문제정의

## 1. 선택한 데이터

| 항목 | 내용 |
|------|------|
| **이름** | Student Performance / Behavior Dataset |
| **출처(URL)** | Kaggle – [Student Performance Factors](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors) *(계획서 기준 추정, 직접 확인 필요)* |
| **라이선스** | CC0: Public Domain *(Kaggle 공개 데이터셋 기준)* |
| **크기** | 약 2,000~6,000행 × 20열 내외 *(실제 다운로드 후 확인 필요)* |
| **형식** | CSV |
| **주요 컬럼** | 공부 시간(주당), 출석률, 스트레스 수준, 성별, 부모 지원 수준, GPA, Final\_Grade 등 |

---

## 2. 풀고 싶은 문제

> **"학생 행동·환경 데이터로 미래 학업 성취도(GPA 및 등급)를 예측하고 싶다"**

- **예측 대상 ①** (회귀): `GPA` – 연속형 수치 예측
- **예측 대상 ②** (분류): `Final_Grade` – A / B / C / D / F 등급 분류
- 핵심 질문: *공부 시간, 출석률, 스트레스 수준 등 행동 변수가 성적에 얼마나 영향을 미치는가?*

---

## 3. 만들 서비스 (완성 모습)

```
[입력] 주당 공부 시간 / 출석률 / 스트레스 수준 / 성별 / 부모 지원 수준
         ↓
[ML 예측] 예상 GPA: 3.4  /  예상 등급: B
         ↓
[LLM 생성] 맞춤형 학습 상담 리포트 (한글, Markdown 출력)
```

| 단계 | 기술 | 역할 |
|------|------|------|
| **EDA 대시보드** | Streamlit + Matplotlib/Seaborn | 히스토그램, 히트맵, 인터랙티브 필터 |
| **ML 예측** | Scikit-learn (Random Forest / XGBoost) | GPA 회귀 + 등급 분류 |
| **AI 컨설팅** | Ollama (Llama3 / Mistral, 로컬 LLM) | 수치 결과 → 자연어 상담 리포트 생성 |

- **입력**: 슬라이더·셀렉트박스로 학생 스탯 직접 입력
- **출력**: 예측 수치 + AI가 생성한 맞춤형 주간 공부 스케줄 & 스트레스 완화 팁

---

## 4. 예상 난관 1가지

**Ollama 로컬 LLM 연동 및 응답 품질 제어**

Ollama를 Streamlit과 연결할 때 **스트리밍 응답 처리**와 **프롬프트 엔지니어링**이 까다롭습니다. ML 모델이 출력한 수치(GPA 3.2, 등급 C)를 LLM 프롬프트에 동적으로 삽입해야 하는데, 프롬프트 구조가 조금만 어긋나도 엉뚱하거나 너무 일반적인 조언이 생성될 수 있습니다. 특히 한국어 응답 품질은 모델(Llama3 vs Mistral vs Qwen)마다 편차가 크므로, **모델 선택 + Few-shot 예시 프롬프트 설계**에 충분한 테스트 시간을 확보해두는 것이 중요합니다.
