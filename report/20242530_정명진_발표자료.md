## 🖼 슬라이드 3 — EDA·시각화 발견 `⏱ 1분`

### 슬라이드에 넣을 것

> **그래프 캡처 2장** (앱 실행 후 스크린샷 삽입 권장)

**그래프 ① — 타겟 클래스 불균형**
- `학업 관리 단계` 파이차트: 저위험 **15%** / 중위험 51% / 관리 필요 34%
- → "저위험이 15%뿐 — 단순 정확도는 의미 없다"

**그래프 ② — 공부 일관성 × 위험도 비율 막대**
- 거의 안 함 → 관리 필요 **74%**
- 대체로 일정 → 관리 필요 **18%**
- → "공부 시간보다 **꾸준함**이 훨씬 강한 예측 변수"

> 💡 **두 그래프만**, 각 그래프 아래 한 줄 결론 텍스트

### 말할 내용

> "EDA에서 두 가지가 가장 눈에 띄었습니다.  
> 첫째, 저위험 학생이 전체의 15%밖에 안 됩니다.  
> 이 불균형 때문에 단순 정확도로는 모델을 평가할 수 없습니다.  
>  
> 둘째, **공부 일관성**이 가장 강력한 예측 변수입니다.  
> '거의 공부를 안 한다'고 응답한 학생의 74%가 관리 필요입니다.  
> 공부 시간이 아니라 **꾸준히 하는가**가 핵심이었습니다."

## 🖼 슬라이드 5 — 특성 엔지니어링 & 분석 결과 `⏱ 1분`

### 슬라이드에 넣을 것

**새로 만든 특성 — SDL 자기주도 학습 지수**

```
SDL 지수 = 공부일관성(0~2) + 복습빈도(0~3)
         + 과제제때제출(0~3) + 과제제출(0~3)
         = 최대 11점
```

| 위험도 | SDL 평균 |
|--------|---------|
| 저위험 | 높음 ↑ |
| 중위험 | 중간 → |
| 관리 필요 | 낮음 ↓ |

**전처리 파이프라인 요약**

```
드롭(2열) → 결측치 처리 → Ordinal Encoding(18열)
→ One-Hot Encoding(11열) → StandardScaler(5열)
→ 최종 약 80열
```

**핵심 분석 수치**

| 발견 | 수치 |
|------|------|
| 공부 일관성 '거의 안 함' → 관리 필요 비율 | **74%** |
| 학업 만족도 '매우 불만족' → 관리 필요 비율 | **65%** |
| 스크린타임 6h+ 대비 2~4h의 생산성 차이 | **+20%** |

> 💡 ML 예측 모델은 향후 과제 (현재는 EDA + 전처리 + 심화 분석)

### 말할 내용

> "단일 변수보다 강한 예측력을 위해 **SDL 자기주도 학습 지수**를 직접 만들었습니다.  
> 4개 행동 변수를 합산한 복합 지수인데,  
> 위험도 그룹별로 SDL이 명확히 구분되는 것을 확인했습니다.  
>  
> 전처리는 원본 36열을 약 80열로 확장하여  
> Random Forest·XGBoost 등 ML 모델 학습이 바로 가능한 상태로 준비했습니다."

## 🖼 슬라이드 6 — 결론 & 한계 `⏱ 30초`

### 슬라이드에 넣을 것

**결과 한 줄**
> "공부 **꾸준함(일관성)**과 자기주도 지수(SDL)가 단일 공부 시간보다 학업 위험도를 훨씬 잘 설명한다."

**한계 1개**
> 저위험(15%) 클래스 불균형 → 단순 Accuracy 무의미, SMOTE 필요

**향후 과제 1개**
> Random Forest + SMOTE로 위험도 분류 모델 학습 → SHAP로 변수 중요도 시각화

### 말할 내용

> "정리하면, 공부 시간보다 **꾸준히 하는가**가 훨씬 중요했습니다.  
> SDL 복합 지수가 이를 잘 포착합니다.  
>  
> 아쉬운 점은 저위험 클래스가 15%뿐이라 ML 모델까지는 완성하지 못했고,  
> 다음 단계로 SMOTE와 Random Forest를 적용할 계획입니다.  
>  
> 감사합니다."

## 💬 예상 질문 & 답변

### Q1. "이 앱이 뭘 입력받아 뭘 출력하나요?"

> "현재 앱은 예측 모델보다 **분석 대시보드** 형태입니다.  
> CSV 데이터를 불러와 EDA 시각화, 전처리 파이프라인 실행, 심화 분석을 제공하며,  
> 전처리된 CSV를 다운로드할 수 있어 ML 모델 학습에 바로 사용할 수 있습니다."

### Q2. "EDA에서 가장 놀란 발견은?"

> "외부 압박 역설입니다.  
> '압박이 전혀 없는 완전 지지 환경' 학생의 관리 필요 비율이  
> '높은 압박' 그룹보다 오히려 더 높았습니다.  
> 외부 동기가 없으면 자기조절 실패가 더 심각하다는 것을 보여줍니다."

### Q3. "SDL 지수는 왜 이 4개 변수를 선택했나요?"

> "공부 일관성·복습 빈도·과제 제때 제출·과제 제출은  
> 모두 '하겠다고 결심하고 실제로 행동하는' 자기주도 행동을 나타냅니다.  
> 이 4개를 합산하면 단일 변수보다 위험도를 더 선형적으로 구분할 수 있어 선택했습니다."

### Q4. "클래스 불균형은 어떻게 해결할 건가요?"

> "현재 단계에서는 탐색적 분석에 집중했고,  
> 다음 단계에서 SMOTE 오버샘플링 또는 `class_weight='balanced'`를 적용할 계획입니다.  
> 평가 지표도 Accuracy 대신 **Macro F1-Score**와 **저위험 Recall**을 주로 볼 것입니다."
