## 1. 문제 정의

### 무엇을, 왜 분석하는가

대학생의 학업 성취도는 단순한 공부 시간만이 아니라 수면·스트레스·출석·자기주도 학습 습관 등 복합적인 행동 변수가 얽혀 결정된다. 이 프로젝트는 1,200명 대학생의 36개 행동·환경 데이터를 활용하여 **"어떤 요인이 학습 관리 단계에 영향을 미치는가"** 를 탐색하고, 나아가 **집중 지원이 필요한 학생을 조기 식별할 수 있는 분석 기반**을 구축하는 것을 목표로 한다. 특히 공부 일관성·자기주도 학습 지수(SDL)·복합 변수 조합 등 단일 변수로는 드러나지 않는 패턴을 발굴해 교육 현장에서 실질적으로 활용 가능한 인사이트를 제공하고자 한다.

### 예측 대상 (Target)

| 구분 | 컬럼명 | 유형 | 설명 |
|------|--------|------|------|
| 타겟 ① | `performance_risk_level` | 다중 분류 | 안정 / 주의 관찰 / 관리 필요 |
| 타겟 ② | `cgpa_category` | 다중 분류 | 5.0~6.9 / 7.0~8.4 / 8.5~9.4 / 9.5~10.0 |

## 2. 데이터 소개 & EDA

### 데이터 규모

| 항목 | 내용 |
|------|------|
| 파일명 | `hybrid_student_performance_1200.csv` |
| 행 수 | 1,200행 |
| 열 수 | 36열 |
| 결측치 있는 컬럼 | 13개 (결측률 2.3 ~ 4.8%) |
| 중복 행 | 0건 |
| 수치형 컬럼 | 5개 (`age`, `daily_productivity`, `energy_level`, `stress_level`, `routine_rating`) |
| 범주형 컬럼 | 31개 (순서형 18 + 명목형 11 + 타겟 2) |

### EDA 주요 발견

#### ① 공부 일관성이 가장 강력한 단일 예측 변수

공부 일관성(`study_consistency`)이 '거의 안 함(Rarely)'인 학생 중 약 **74%** 가 '관리 필요' 단계에 해당하며, 이는 출석률·공부 시간 등 다른 단일 변수보다 훨씬 강한 예측력을 보인다.

```
공부 일관성     관리 필요 비율
거의 안 함   →  ≈ 74%
가끔         →  ≈ 42%
대체로 일정  →  ≈ 18%
```

#### ② 타겟 변수의 심각한 클래스 불균형

`performance_risk_level` 분포가 극도로 불균형하여, 단순 정확도(Accuracy)만으로 모델 성능을 평가할 수 없다.

| 학업 관리 단계 | 학생 수 | 비율 |
|--------------|---------|------|
| 안정 | 176명 | **15%** |
| 주의 관찰 | 612명 | 51% |
| 관리 필요 | 408명 | 34% |

> 모델 학습 시 SMOTE 오버샘플링 또는 `class_weight='balanced'` 설정이 필수적이다.

#### ③ 외부 압박 역설 (Paradox of External Pressure)

직관과 반대로, **'압박 없음(완전 지지 환경)'** 그룹에서 관리 필요 비율이 **'높은 압박'** 그룹보다 오히려 높게 나타난다. 이는 외부 동기 부재 시 자기조절 실패가 더 심각함을 시사한다.

```
외부 압박 없음  →  관리 필요 비율 ≈ 37%
외부 압박 높음  →  관리 필요 비율 ≈ 34%
```

#### ④ 번아웃 복합 패턴

스트레스 高(7~10점) + 에너지 低(1~3점) 조합 구간에서 관리 필요 비율이 가장 높게 집중된다. 비학습 스크린타임도 생산성과 역상관 관계를 보인다.

| 스크린타임 | 평균 생산성 |
|-----------|------------|
| 2~4시간   | 3.05 |
| 4~6시간   | 2.76 |
| 6시간 초과 | 2.55 |

### 결측치 및 이상치 처리

| 처리 전략 | 대상 |
|----------|------|
| **중앙값 대체** | 수치형 컬럼 (결측률 낮고 분포 왜도 존재) |
| **최빈값 대체** | 범주형 컬럼 (명목형 및 순서형 모두) |
| 이상치 처리 | 수치형 5개 컬럼 모두 Likert 척도(1~10) 기반으로 자연 범위 내에 있어 별도 제거 불필요 |

## 3. 특성 엔지니어링

### SDL 자기주도 학습 지수 (Self-Directed Learning Index)

**근거**: 단일 변수로는 포착하기 어려운 '자기주도 학습 역량'을 복합 지표로 수치화하기 위해 4개 행동 변수를 Ordinal 인코딩 후 합산한 복합 특성을 새로 생성하였다.

$$\text{SDL 지수} = \text{공부일관성} + \text{복습빈도} + \text{과제제때제출} + \text{과제제출}$$

| 구성 변수 | 인코딩 범위 | 가중치 |
|----------|------------|--------|
| `study_consistency` (공부 일관성) | 0 ~ 2 | 균등 |
| `revision_frequency` (복습 빈도) | 0 ~ 3 | 균등 |
| `tasks_on_time` (과제 제때 제출) | 0 ~ 3 | 균등 |
| `assignments_on_time` (과제 제출) | 0 ~ 3 | 균등 |
| **합계 (최대)** | **0 ~ 11** | — |

**검증**: SDL 지수가 낮은 그룹에서 '관리 필요' 비율이 유의미하게 높으며, CGPA 구간이 높을수록 SDL 평균이 선형적으로 증가하는 패턴이 확인된다.

### Ordinal Encoding (순서형 범주 → 정수)

18개 순서형 컬럼에 대해 의미적 순서를 보존한 정수 매핑을 적용한다.  
예: `attendance_percentage` → 50%미만(0), 50~65%(1), 66~75%(2), 76~85%(3), 85%초과(4)

### One-Hot Encoding (명목형 범주)

`gender`, `program_stream`, `career_interest` 등 11개 명목형 컬럼에 OHE를 적용하여 순서 정보가 없는 범주를 수치화한다.

| 구분 | 컬럼 수 | 결과 컬럼 수 |
|------|---------|-------------|
| 원본 | 36 | — |
| 드롭 | 2 (`student_id`, `timestamp`) | — |
| OHE 전 | 34 | — |
| OHE 후 | — | **약 80열** |

## 4. 모델 / 서비스

### 사용한 방법: 탐색적 데이터 분석(EDA) + 전처리 파이프라인

현재 구현 단계는 **완전한 데이터 이해 및 전처리 완료** 단계이며, Streamlit 앱을 통해 EDA 결과와 심화 분석을 인터랙티브하게 제공한다. ML 예측 모델 학습은 다음 단계로 계획되어 있다.

#### 현재 구현 흐름

```
[입력] hybrid_student_performance_1200.csv (1,200행 × 36열)
         ↓ 드롭 (student_id, timestamp)
         ↓ 결측치 처리 (수치형 중앙값 / 범주형 최빈값)
         ↓ Ordinal Encoding (18개 순서형 컬럼)
         ↓ One-Hot Encoding (11개 명목형 컬럼)
         ↓ StandardScaler (5개 수치형 컬럼)
[출력] 전처리 완료 CSV + 인터랙티브 EDA 대시보드
```

#### 계획된 ML 모델 (향후)

| 모델 | 역할 | 선택 이유 |
|------|------|----------|
| Random Forest | 다중 분류 (학업 관리 단계 예측) | 결측 강건성, Feature Importance 제공 |
| XGBoost | 다중 분류 (CGPA 구간 예측) | 클래스 불균형에 강함, 고성능 |
| SMOTE | 전처리 (안정 그룹 오버샘플링) | 안정 15% 재현율 향상 |
| SHAP | 해석 | 어떤 변수가 예측에 핵심인지 시각화 |

#### 현재 심화 분석 성과

EDA 단계에서 도출된 주요 수치 결과:

| 분석 항목 | 핵심 수치 |
|----------|----------|
| 공부 일관성 '거의 안 함' → 관리 필요 비율 | **≈74%** |
| 학업 만족도 '매우 불만족' → 관리 필요 비율 | **≈65%** |
| SDL 지수 최저 그룹 vs 최고 그룹 차이 | **약 3배 이상** |
| 스크린타임 6h+ vs 2~4h 생산성 차이 | **−16%** |

## 5. Streamlit 앱

### 페이지 구성

앱은 4개 탭으로 구성되며, 사이드바 없이 탭 단위로 분석 항목을 전환한다.

| 탭 | 내용 |
|----|------|
| 📋 **데이터 개요** | 행/열/결측치/중복 요약, 샘플 데이터, 컬럼 정보, 기술통계 |
| 🔍 **EDA** | 타겟 분포 / 수치형 변수 / 범주형 변수 / 상관관계 히트맵 / 변수×타겟 관계 (라디오 선택) |
| ⚙️ **전처리** | 드롭 → 결측치 → Ordinal → OHE → 스케일러 순서로 expander 정리, 전처리 실행 버튼, CSV 다운로드 |
| 🧪 **심화 분석** | 복합 조합 / 역설 케이스 / 만족도 경로 / 스크린타임 / 외부압박 역설 / SDL 지수 / 진로×성취도 / 시간대 분석 / 추가 로드맵 (9개 섹션) |

### 기술 스택

| 라이브러리 | 역할 |
|-----------|------|
| `streamlit` | 웹 대시보드 프레임워크 |
| `pandas` | 데이터 처리 및 집계 |
| `matplotlib` / `seaborn` | 정적 시각화 |
| `scikit-learn` | Ordinal Encoding, StandardScaler |
| `numpy` | 행렬 연산 |

### 실행 방법

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 앱 실행
streamlit run app.py
```

> 브라우저에서 자동으로 `http://localhost:8501` 이 열립니다.

## 6. 결론 & 한계

### 알게 된 것

1. **공부 일관성(study_consistency)** 이 단일 변수 중 가장 강력한 예측 변수이다. 공부 시간·출석률보다 '꾸준함'이 더 중요하다.

2. **SDL 자기주도 학습 지수** 는 4개 변수의 단순 합산만으로도 학업 관리 단계를 선형적으로 구분하는 복합 지표로서 유효함이 확인되었다. '관리 필요' 그룹의 SDL 평균은 '안정' 그룹의 절반 수준이다.

3. **외부 압박 역설** — '압박이 없는 완전 지지 환경'의 학생이 오히려 관리 필요 비율이 더 높다. 이는 외부 동기가 없을 때 자기조절에 더 많은 노력이 필요함을 의미한다.

4. **번아웃 복합 패턴** — 스트레스 高 + 에너지 低 + 공부 일관성 低가 겹치는 구간에서 관리 필요 학생이 집중된다. 이 세 조건이 동시에 충족될 때 지원 개입이 가장 시급하다.

5. **클래스 불균형의 심각성** — '안정' 단계(15%)가 극소수이므로 단순 정확도로는 모델이 항상 '주의 관찰' 또는 '관리 필요'만 예측해도 85% Accuracy가 나올 수 있다. **재현율(Recall)과 F1-Score** 가 핵심 지표다.

### 아쉬운 점 / 향후 과제

| 한계 | 향후 과제 |
|------|----------|
| ML 예측 모델 미구현 | Random Forest / XGBoost 학습 + SMOTE 적용 |
| 단면(Cross-sectional) 데이터로 인과 추론 불가 | 종단 연구(Longitudinal Study) 설계 |
| 자기보고 편향(Self-report Bias) 가능성 | 객관적 성적 데이터(LMS 로그 등) 추가 수집 |
| SHAP 특성 중요도 분석 미완성 | 모델 학습 후 SHAP 값 시각화 추가 |
| LLM 맞춤형 상담 리포트 미구현 | Ollama 연동으로 SDL 점수 기반 개인 맞춤 학습 전략 생성 |
| 학교/전공별 맥락 차이 미고려 | program_stream 서브그룹 분석 고도화 |
